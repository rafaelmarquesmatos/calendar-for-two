# Calendar for Two

Um calendário compartilhado para casais: datas, planos e lembretes num só
lugar.

## Stack

- React 19 + TypeScript (strict)
- Vite 8
- Tailwind CSS v4
- shadcn/ui (estilo radix-nova, preset nova, ícones lucide)
- React Router

## Estrutura

- `frontend/` — aplicação front-end (ativa)
- `backend/` — planejado para o futuro

Veja [AGENTS.md](./AGENTS.md) para a arquitetura completa, regras e comandos.

## Desenvolvimento

```bash
cd frontend
npm install
npm run dev
```

Acesse http://localhost:5173.
